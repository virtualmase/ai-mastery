# Section 08 source notes

## Scope

Section 08 is educational. It will describe economic primitives and agentic-commerce workflow boundaries, not recommend investments, payment products, cryptocurrencies, or financial actions. It will not claim that an agent can safely transact, that a protocol guarantees settlement, or that any vendor solution is production-ready.

## Candidate primary sources

- BIS, *The next-generation monetary and financial system*: https://www.bis.org/publ/arpdf/ar2025e3.htm
- ISO 20022 message definitions: https://www.iso20022.org/iso-20022-message-definitions
- JSON-RPC 2.0 specification: https://www.jsonrpc.org/specification
- Agent2Agent Protocol specification: https://a2a-protocol.org/latest/specification/
- Model Context Protocol specification: https://modelcontextprotocol.io/specification/2025-06-18
- PCI Security Standards Council, PCI DSS: https://www.pcisecuritystandards.org/standards/pci-dss/
- NIST AI Risk Management Framework: https://www.nist.gov/itl/ai-risk-management-framework

## Proposed lesson boundaries

1. Value, price, payment, settlement, and fulfillment are distinct stages; a payment message or authorization is not proof of completed delivery.
2. Agent mandates and spend limits must be represented as policy and authority boundaries; a tool or wallet interface is not consent by itself.
3. Reconciliation, disputes, refunds, and exceptions are workflow primitives; a terminal status is not a verified business outcome.
4. Economic models should name incentives, fees, counterparties, risk allocation, and failure handling without predicting adoption or profitability.
