Autonomous Resource Management

Map resources, authority, trace records, and exceptions before an agent acts.

Working artifact

resource map

AURE-04 produces a bounded resource map that names owners, decision rights, limits, evidence, and escalation routes.

  1. Name the actor and the decision.
  2. Record the evidence source and observation date.
  3. Set the authority boundary and unresolved question.
  4. Choose the next review event. Missing evidence stays unknown.
