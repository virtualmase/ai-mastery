# AI Mastery

AI Mastery is Mason Nguyen's technical knowledge and systems architecture platform for artificial intelligence, knowledge systems, agentic computing, production infrastructure, and digital trust.

The interface uses a Windows 95-inspired operating-system metaphor drawn from Mason's [VIRTUALMASE portfolio](https://virtualmase.vercel.app/) and his account of first discovering computers on a Hewlett-Packard desktop in first grade. The closed-loop thesis follows his essay [You Don't Need More Content. You Need a Closed Loop.](https://paragraph.com/@corenuten/you-dont-need-more-content-you-need-a-closed-loop).

The built-systems registry connects the research to Mason's shipped work: [Coreweaver Labs](https://coreweaverlabs.com/), [Swell Marketing](https://swellmarketing.xyz/), and [Arctura Network](https://arctura.network/), launched on Bittensor's testnet as subnet 505.

## Local preview

No build step or package installation is required.

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

## Deployment

The site is a zero-dependency static document and can be served from GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static web server. Canonical discovery files currently target `https://virtualmase.github.io/ai-mastery/`; update them together if a custom domain is connected.

## Discovery surface
